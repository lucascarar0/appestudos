# Gradua

App de estudos para graduação (organizado por curso e disciplina): resumo, mapa mental, explicação, casos, provas e biblioteca de links. Funciona sem internet e sem IA.

- **Abrir:** dê dois cliques em `index.html` ou publique pelo GitHub Pages.
- **Editar com o Claude:** veja `CLAUDE.md`, que explica a estrutura e as regras do projeto.
- **Conteúdo:** escrito à mão e com referências reais; precisa de revisão profissional (principalmente saúde e direito).
